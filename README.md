# IR-NLP

IR & NLP Repository for the CAU course.

## Content

The objective is to retrieve some data and create a data collection.Then build an IR System with:

- Boolean Model (exact logic-based search)
- Vector Space Model (TF-IDF)
- LSI Model (Latent Semantic Indexing)

The collection is built by scraping articles from the [venturebeat.com](https://venturebeat.com) website related to AI news.

## Dependencies

You need Python to run the project.
Install dependencies with:

```bash
pip install -r requirements.txt
```

## How to Generate the Dataset ?

- By using `python3 Scrap.py` all the articles that can be found on venturebeat.com will be stored in 'articles.json' file.
- You can use `python3 IsolateText.py` to generate txt based on every articles, they will appear inside 'articles_txt' folder.

## How to use IR System ?

- Launching python file with `python3 IRSystem.py` you will have access to the IRSystem console.

  You can use 3 types of queries :

### 🔹 Boolean Search

Use plain words or Boolean logic:

- `'ai'` → finds all documents containing "ai"
- `'ai OR openai'` → finds documents containing either "ai" or "openai"
- `'ai AND openai'` → finds documents containing both

### 🔹 Vector Space Model (TF-IDF)

Use the keyword `'vector'` :

```
vector ai openai
```

This ranks documents by similarity to your query.

### 🔹 LSI (Latent Semantic Indexing)

Use the keyword `'lsi'`:

```
lsi ai robotics
```

This finds documents semantically close to your query (not limited to exact words).

## Evalutation of Precision and Recall

For evaluation of the precision and recall in boolean IR :

```bash
python precision_recall.py
```

This will:

- Compare retrieval effectiveness using precision, recall, and F1-score.
- Print evaluation results in the terminal.
- Save results to:
  - `boolean_evaluation_results.json`
  - `lsi_evaluation_results.json`

Ground truth is automatically generated by checking term presence in documents.

## Notes

- Boolean search is strict and accurate for exact term matching.
- LSI adds semantic search capability, useful for discovering related content even when words differ.
- Combining both approaches gives the best of both worlds.
